How each style is built

Every style on this page is plain Unicode text. Some add combining marks to your letters, some swap in lookalike characters, and some simply reorder the string. A cursed text generator usually bundles several of these techniques, and knowing which is which helps you pick the one that survives your platform.

Choosing a style

When readability matters

Reversed, void and underline keep your letters visible and are the safest picks for bios and captions.

When you want maximum horror

Heavy zalgo and melting give the strongest effect, but expect some apps to clip them. Keep a lighter version ready as a fallback.

When you need it to survive filters

Styles that use one mark per letter, such as strikethrough or slash, are far more likely to pass a filter than dense stacks.

Mix and match

Paste a result back into the input and apply another style. Marks from different styles combine freely, and a reversed line with a light zalgo on top is a favourite.

Style questions

What is the difference between zalgo and strikethrough text?

Both use combining marks. Zalgo piles many random marks above and below each letter. Strikethrough adds exactly one overlay mark, U+0336, to every letter, which draws a line through it.

Why does upside-down text change the letters?

Upside-down text does not rotate anything. It swaps each letter for a different Unicode character that happens to look like the rotated letter, and then reverses the order of the string.

Which style is the most compatible?

Reversed text and fullwidth text use ordinary characters, so they work almost everywhere. Styles that rely on combining marks depend on the app and font.

Why do slash and strike text look different in different apps?

Overlay marks are drawn by the font engine. Some fonts line them up neatly, others offset them. If the line sits too high or too low, try a different app or font.

Can I combine two styles?

Yes. Paste the result of one style into the input box and apply another. Reversed text with a light zalgo on top is a popular combination.

Is there a limit on how much text I can style?

The box here allows 200 characters, which suits names, bios and short captions. Longer text works, but marks add up quickly and some apps will truncate them.
